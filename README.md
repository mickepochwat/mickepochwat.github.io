# Website for GitHub Pages (mickepochwat.github.io)

It is then served at:

| URL | File |
|---|---|
| https://mickepochwat.github.io/ | `index.html` |
| https://mickepochwat.github.io/aquamind/privacy/ | `aquamind/privacy/index.html` ← privacy policy URL for Play + AdMob |
